A helix-feeling coding (and more) environment for agentic development.

It combines functionality from a code editor, terminal multiplexer, file manager and more, to create a seamless experience using agentic systems.

Codon aims to be be my unique tool for most of my common tasks, and to be a platform for building agentic systems.
It is designed to be highly customizable and extensible, but it is very tailored to my specific needs and preferences. It may not be suitable for everyone, but feel free to try it out and see if it works for you.

> [!NOTE]
> **I've done a little bit of guided cleanup and refactoring, but most if not all of the work has been done through coding agents.**
>
> This is a huge project I wouldn't have been able to tackle on my own, you may not like coding agents and the code they generate
> (which is often ugly, for sure). But they make this small fun projects possible and that's just fantastic.
